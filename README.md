# Pride Advisory — Fundamental Analyzer (Streamlit)

This repository contains a Streamlit app that computes multi-year financial ratios and runs a DCF valuation.

## Requirements

- Python 3.9+
- pip

Install dependencies:
```bash
python -m venv .venv
source .venv/bin/activate   # mac/linux
# .venv\Scripts\activate    # windows powershell
pip install -r requirements.txt
